四个训练阶段怎么用合成数据

四个阶段用的是同一套生成器：同一个 draw、同一个 MultiPool（一半的行耦合、6 种机制、lag_max = 256）、同一个 post、同一组单变量增强（0.4，mix / season / filter / lattice）。真正的差别只有六个开关：合成占比、每行长度、族列表与权重、duty 观测、协变量角色与效应行、协变量 pass。生成流水线本身见生成流程，原理细节见数据生成指南。

角色只分配给至少 2 个成员、且没有被时间翻转的耦合组。谁当协变量：lag、event、带根的 func 让根成员各以 0.8 的概率成为协变量；其他机制（包括 identity，此时协变量是纯干扰项）每个成员以 U(0.2, 0.5) 的比例。至少留 1 个目标、最多 8 个协变量；50% 的角色组给目标加 1–16 个 patch 的末端遮挡；15% 的协变量只知道到 [0.75L, L) 的某一步。

五个效应族

族造的是什么lead-lag 与时间相关的部分
generic8 类协变量：预报、天气、促销、关闭、价格、排班、设定值、干扰项，带交互、对数模式与切换预报误差随提前量增长（_issue）；周期 70% 取底序列的 FFT 峰
classicalF0–F9：传递函数、干预、动态回归、天气-负荷 / 光伏 / 风、营销（Bass / adstock / 价格）、容量排队、交互、发布的预报传递函数延迟至多 64 步；干预带前导与回落；freq_label + Cal(freq)，t0 ∈ [0, 1e6)
energy负荷、光伏、风电、电价、电价档，以及 TSO 预报每天 24 / 48 / 96 / 288 步；发布时刻 6–12 点，D-1 / D-2，latest 或 archive 两种取法
retailSCAN*PRO 式的乘性提升（上限 4）：促销段的降价、促销标志、40% 有促销后回落，以及干扰项50% 是带星期效应的日数据，50% 是带年周期（52）的周数据
lagged1–8 个协变量，25% 是干扰项；阈值、差分、tanh 等变换30% 无滞后，否则滞后 LogU(1, 512) 步；10% 叠一段负向平移，提前 1–32 步

每组预测长度 H 取自 {1, 2, 3, 4, 6, 8, 12, 16} 个 patch，目标最后 H 步就是末端遮挡块；40% 的组做左截断，观测长度 LogU(max(1024, H + 256), L)；30% 的目标取反。

三个容易误解的地方

① 「40% 合成」指的是打包后的行，不是窗口数，也不是 token 数。784 个真实窗口先打包，最后 40% 的行被整行覆盖，落在里面的真实窗口直接丢弃；数据计划已经按 1 − 0.4 预算过真实 token。
② 阶段 3/4 的合成数据不训练远区：合成行只有近区 4608 步，远区全是 NaN。远区的池化 token 只在阶段 1/2 见过合成数据。
③ 效应行只在阶段 2：配置校验禁止 stage: stage2 的运行带 effect_share。阶段 3/4 改用协变量 pass，而它的 synthetic 窗口是在真实底序列上合成协变量与效应，不是纯合成序列。
